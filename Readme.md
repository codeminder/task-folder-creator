# Obsidian Task Creator

Утиліта для швидкого створення структури задачі в Obsidian.

Скрипт відображає діалогове вікно, дозволяє ввести дату, ID заявки, URL, заголовок та вимоги, після чого автоматично:

1. Створює каталог задачі за заданим шаблоном.
2. Генерує Markdown-файл на основі шаблону.
3. Заповнює службові поля метаданих.
4. Записує вимоги в тіло документа.
5. Формує клікабельне посилання на заявку.

---

# Можливості

- Графічний інтерфейс на базі `tkinter`.
- Вибір дати створення задачі.
- Необов'язковий ID заявки.
- Необов'язковий URL заявки.
- Багаторядкове поле «Вимоги».
- Обов'язковий заголовок задачі.
- Автоматичне створення каталогу.
- Автоматичне створення нотатки Obsidian.
- Підстановка значень у шаблон.
- Автоматична заміна заборонених символів.
- Обрізання довгих назв каталогів.
- Підтримка Windows, Linux та macOS.

# Конфігурація

Всі налаштування зберігаються у файлі `config.ini`.

## Приклад config.ini

```ini
[paths]
base_directory = D:\Obsidian\Tasks
template_file = D:\Obsidian\Templates\task.md
```

## Параметри

### base_directory

Каталог, у якому створюються папки задач.

Приклад:

```text
D:\Obsidian\Tasks
```

### template_file

Повний шлях до Markdown-шаблону Obsidian.

Приклад:

```text
D:\Obsidian\Templates\task.md
```

# Інтерфейс

При запуску відображається діалог з такими полями.

## Дата

Обов'язкове поле.

Формат:

```text
YYYY-MM-DD
```

За замовчуванням використовується поточна дата.

---

## ID заявки

Необов'язкове поле.

Приклад:

```text
INC123456
```

---

## URL

Необов'язкове поле.

Приклад:

```text
https://dev.azure.com/company/project/_workitems/edit/123456
```

---

## Вимоги

Необов'язкове багаторядкове поле.

У нього можна вставляти:

- текст;
- списки;
- markdown;
- фрагменти листування;
- опис задачі.

Приклад:

```text
1. Додати перевірку параметрів.
2. Забезпечити сумісність зі старими даними.
3. Оновити документацію.
```

---

## Заголовок

Обов'язкове поле.

Приклад:

```text
Оновлення модуля синхронізації
```

---

# Команди

## Створити

## Відмінити

Закриває діалог без змін.

# Формування каталогу

Каталог створюється за шаблоном:

```text
YYMMDD-ID-Заголовок
```

або

```text
YYMMDD-Заголовок
```

якщо ID відсутній.

## Приклад

Вхідні дані:

```text
Дата: 2026-07-24
ID: INC123456
Заголовок: Оновлення модуля синхронізації
```

Результат:

```text
260724-INC123456-Оновлення модуля синхронізації
```

---

# Обробка заборонених символів

Для сумісності із файловими системами символи

```text
< > : " / \ | ? *
```

замінюються на

```text
_
```

---

# Обмеження довжини

Максимальна довжина імені каталогу:

```text
230 символів
```

Якщо заголовок занадто довгий, він автоматично обрізається.

---

# Формування нотатки

У каталозі створюється файл:

```text
<Заголовок>.md
```

Приклад:

```text
Оновлення модуля синхронізації.md
```

---

# Шаблонні змінні

У шаблоні підтримуються наступні змінні:

| Змінна | Опис |
|---------|---------|
| `{{ title }}` | Заголовок |
| `{{ task_id }}` | ID заявки |
| `{{ url }}` | URL заявки |
| `{{ url_block }}` | Блок із клікабельним URL |
| `{{ requirements }}` | Вимоги |
| `{{ created_at }}` | Дата створення |
| `{{ updated_at }}` | Дата оновлення |

---

# Формат дат

Для полів `created_at` та `updated_at` використовується формат:

```text
YYYY-MM-DD HH:MM
```

Приклад:

```text
2026-07-24 14:35
```

---

# Клікабельний URL

При заповненні поля URL формується блок:

```markdown
**URL:** https://dev.azure.com/company/project/_workitems/edit/123456
```

У Obsidian посилання автоматично стає клікабельним.

Якщо URL не заповнений, блок не додається в документ.

# Особливості Windows

Під час тестування було виявлено особливість `Tkinter/Tcl` під Windows.

## Симптом

В українській або російській розкладці клавіатури:

```text
Ctrl + V
```

може не працювати в полях вводу.

При цьому:

```text
Shift + Insert
```

працює коректно.

Також:

```text
Ctrl + V
```

працює при англійській розкладці.

## Рекомендації

У разі виникнення проблеми:

1. Тимчасово переключитися на англійську розкладку.
2. Використовувати:

```text
Shift + Insert
```

для вставки.
3. Розглянути додавання контекстного меню:

```text
Копіювати
Вирізати
Вставити
Виділити все
```

в наступних версіях проєкту.
