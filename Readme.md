# Obsidian Task Creator

Утиліта для швидкого створення структури задачі в Obsidian.

Скрипт відображає діалогове вікно, дозволяє ввести дату, ID заявки та заголовок, після чого автоматично:

1. Створює каталог задачі за заданим шаблоном.
2. Генерує Markdown-файл на основі шаблону.
3. Заповнює службові поля метаданих.

---

## Можливості

- Графічний інтерфейс на базі `tkinter`.
- Вибір дати створення задачі.
- Необов'язковий ID заявки.
- Обов'язковий заголовок задачі.
- Автоматичне створення каталогу.
- Автоматичне створення нотатки Obsidian.
- Підстановка значень у шаблон.
- Автоматична заміна заборонених символів.
- Обрізання довгих назв каталогів.
- Підтримка Windows, Linux та macOS.

## Налаштування

На початку скрипта необхідно налаштувати дві глобальні змінні:

```python
BASE_DIRECTORY = r"D:\Obsidian\Tasks"
TEMPLATE_FILE = r"D:\Obsidian\Templates\task.md"
```

### BASE_DIRECTORY

Каталог, у якому будуть створюватися папки задач.

Приклад:

```text
D:\Obsidian\Tasks
```

### TEMPLATE_FILE

Повний шлях до Markdown-шаблону Obsidian.

Приклад:

```text
D:\Obsidian\Templates\task.md
```

## Інтерфейс

При запуску відкривається діалог із такими полями:

### Дата

Обов'язкове поле.

За замовчуванням підставляється поточна дата.

Формат:

```text
YYYY-MM-DD
```

Приклад:

```text
2026-07-24
```

### ID заявки

Необов'язкове поле.

Приклад:

```text
INC123456
```

### Заголовок

Обов'язкове поле.

Приклад:

```text
Не працює синхронізація SharePoint
```

---

## Команди

### Створити

Створює каталог та нотатку.

### Відмінити

Закриває діалог без змін.

---

## Формування каталогу

Папка створюється за шаблоном:

```text
YYMMDD-ID-Заголовок
```

або

```text
YYMMDD-Заголовок
```

якщо ID заявки не вказаний.

### Приклад

Заявка:

```text
Дата: 2026-07-24
ID: INC123456
Заголовок: Не працює синхронізація SharePoint
```

Результат:

```text
260724-INC123456-Не працює синхронізація SharePoint
```

---

## Обробка заборонених символів

Для сумісності з файловою системою символи

```text
< > : " / \ | ? *
```

замінюються на

```text
_
```

### Приклад

Було:

```text
INC/123
```

Стане:

```text
INC_123
```

---

## Обмеження довжини каталогу

Максимальна довжина імені каталогу:

```text
230 символів
```

Якщо заголовок занадто довгий, він автоматично обрізається.

---

## Формування нотатки

У створеному каталозі створюється файл:

```text
<Заголовок>.md
```

### Приклад

```text
Не працює синхронізація SharePoint.md
```

Заголовок проходить ту ж очистку від заборонених символів.

---

## Підтримувані шаблонні змінні

У файлі шаблону можуть використовуватися наступні змінні:

| Змінна | Опис |
|---------|---------|
| `{{ title }}` | Заголовок задачі |
| `{{ task_id }}` | ID заявки |
| `{{ created_at }}` | Дата та час створення |
| `{{ updated_at }}` | Дата та час оновлення |

---

## Формат дат

Для полів `created_at` та `updated_at` використовується формат:

```text
YYYY-MM-DD HH:MM
```

Приклад:

```text
2026-07-24 14:35
```

---

- Вбудований календар для вибору дати.
- Автоматичне відкриття створеної нотатки в Obsidian.
- Автоматичне відкриття створеного каталогу в Explorer/Finder.
